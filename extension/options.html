Suarify Voice Browser

Speak to control the tab you're in. The extension sends your transcript + a page snapshot to a decision endpoint — TypeSafe Jev by default, or any compatible server you plug in.

When on, every clickable element gets a number (click-by-voice style) and you can say a bare number to click it.
Why a configurable endpoint?

The original server app called the TypeSafe SDK from Node. The extension speaks the same wire protocol (POST {endpoint} with a Bearer key) from a service worker, so the endpoint is swappable: keep https://api.typesafe.ai for real Jev, or point at a local proxy / your own decision server for free testing. A bare base URL gets /v1/systemone appended; a URL with a path is used verbatim.
