Voice Browser — Settings

The extension sends your spoken transcript + a page snapshot to a Jev decision engine. Point it at TypeSafe, or at any compatible endpoint (e.g. a localhost proxy) for testing.

When on, every clickable element gets a number (click-by-voice style) and you can say a bare number to click it.
Why a configurable base URL?

The original server app called the TypeSafe SDK from Node. The extension uses the same wire protocol (POST {baseUrl}/v1/systemone with a Bearer key) but from a service worker, so the endpoint can be swapped. Use https://api.typesafe.ai for the real Jev model, or point at a local reimplementation for free testing.
